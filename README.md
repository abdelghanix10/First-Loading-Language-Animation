# First Loading Language Animation

A captivating loading animation that greets users in multiple languages before revealing the main content.

## Description

This project features a smooth loading screen animation that cycles through "Hello" greetings in various languages (English, French, Hindi, Italian, Portuguese, Japanese, Swedish, German, Dutch, Bengali) accompanied by animated dots. After the greetings, the loading screen transitions to reveal the main content with a "Make it Happen" message.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP (GreenSock Animation Platform) for smooth animations

## How to Run

Simply open the `index.html` file in any modern web browser to view the animation.

## Features

- Multilingual greeting animation
- Smooth transitions using GSAP
- Responsive design
- Custom fonts (Raleway, Syne, Instrument Serif)

## Browser Support

Works in all modern browsers that support CSS transforms and GSAP.
